## Contributing

Thanks for considering a contribution! This project is a simple GitHub Pages site, so changes are typically content or documentation tweaks.

### How to Contribute
- Open an issue describing the change you propose (bug, improvement, question).
- For small fixes, feel free to open a pull request directly.
- Keep changes focused and minimal; unrelated changes should be separate PRs.

### Pull Request Checklist
- Update or add documentation where it helps users (README or `docs/`).
- Keep the style consistent with existing files.
- Verify the site builds locally with Jekyll if you changed layouts/config.

### Development Notes
See `docs/local-development.md` for local preview instructions.

### Code of Conduct
Please be respectful and constructive. If needed, add a formal `CODE_OF_CONDUCT.md`.
